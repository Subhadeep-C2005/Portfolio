# Personal Portfolio Website

A clean, responsive, and performance-optimized personal portfolio website to showcase my skills, projects, and milestones as a software developer. 

🔗 **[View Live Site](https://portfolio-taupe-nine-72.vercel.app)** 

## ✨ Features

*   **Dark/Light Mode Toggle:** Seamless theme switching utilizing CSS variables (`:root` and `[data-theme="dark"]`).
*   **Fully Responsive:** Fluid typography and layout using CSS Grid and Flexbox to ensure the UI looks great on mobile, tablet, and desktop.
*   **Zero Dependencies:** Built entirely with Vanilla HTML, CSS, and JavaScript for maximum performance and lightning-fast load times.
*   **Interactive UI:** Includes scroll-reveal animations, a sticky frosted-glass navigation bar, and hover states for project cards.
*   **One-Click Copy:** Built-in clipboard functionality for easy email contact.

## 🛠️ Tech Stack

*   **Structure:** HTML5
*   **Styling:** CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
*   **Interactivity:** Vanilla JavaScript (Intersection Observer API, DOM Manipulation)
*   **Typography:** Google Fonts (Sora, Inter, JetBrains Mono)
*   **Deployment:** Vercel

## 💻 Running Locally

Since this is a static website built with vanilla web technologies, running it locally is incredibly simple.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Subhadeep-C2005/portfolio.git](https://github.com/Subhadeep-C2005/portfolio.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd portfolio
    ```
3.  **Open the site:**
    Simply double-click the `index.html` file to open it in your default web browser. Alternatively, you can use the VS Code "Live Server" extension for hot-reloading during development.

## 📁 File Structure

*   `index.html`: The core entry point containing all markup, embedded CSS styling, and JavaScript logic.
*   `Subhadeep_Chakraborty_-_Resume.pdf`: Downloadable resume linked directly in the hero section. *(Ensure this file is uploaded to your root folder!)*
